Read this before planning a merge

  • A Permission Set adds access. It cannot remove access granted by the base profile or preserve a denial by itself.
  • A missing XML entry is shown as Not specified, not automatically treated as a denial.
  • Layouts, login hours, and IP ranges are profile settings; the tool flags them to keep on the profile for review.
  • Permission Set Groups bundle Permission Sets for a stable user persona. XML differences alone are not enough to decide which users or business functions belong in a group.
  • This compares the two files only. It does not inspect user assignments, existing Permission Sets, role hierarchy, sharing, validation rules, flows, or other org references.
