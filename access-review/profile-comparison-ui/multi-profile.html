STEP 4 · OPTIONAL DETAIL

Before using the recommendations

  • A Permission Set adds access. It cannot remove access granted by the base profile or preserve a denial by itself.
  • The tool compares supplied XML only. It does not inspect existing PS/PSG assignments, role hierarchy, sharing, territories, user needs, or profile-name references elsewhere.
  • Profile-only settings such as layouts, login hours, and IP ranges stay outside generated Permission Sets and must be preserved separately.
  • Confirm target personas and named user assignments with business/security owners, then validate grants and denials in a sandbox.
